Danger zone

This deletes every booking and expense stored in this browser. It cannot be undone — export first.

⚠ How secure is this, really? This console runs entirely in your browser because the site has no server. The password check keeps casual visitors out, but someone technical can bypass it, and all data sits in this one browser — clearing your site data deletes it. Export regularly, and move to a server-side login before this holds anything you would be upset to lose or leak.
